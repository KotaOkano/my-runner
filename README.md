# my-runner

A simple Python script runner for Linux.

## Features

- Run Python and shell scripts
- Pass command-line arguments
- Display execution results
- Manage running processes

## Requirements

- Linux
- Python 3.8 or later
- python3-tk

## Installation

Download the `.deb` package from the Releases page and install it with:

sudo apt install ./my-runner_1.0.0_all.deb
